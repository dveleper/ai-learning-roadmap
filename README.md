# English + AI Engineering — Portal de seguimiento

Sitio estático listo para GitHub Pages. Abre `index.html` localmente para probarlo.

## Publicar en GitHub Pages
1. Crea un repositorio público llamado `ai-learning-roadmap` en GitHub (sin archivos corporativos).
2. Sube `index.html` a la raíz del repositorio.
3. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/(root)`, y guarda.
4. GitHub mostrará la URL pública cuando termine la publicación, normalmente `https://TU-USUARIO.github.io/ai-learning-roadmap/`.

## Actualizar el progreso
- Marca clases completadas y escribe notas en el navegador.
- **Importante:** se guarda en `localStorage` del navegador, no se sincroniza entre dispositivos ni se publica en GitHub.
- Exporta periódicamente el JSON y vuelve a importarlo si cambias de navegador.
- Para sincronización entre dispositivos o actualizaciones automáticas después de cada clase se requiere backend/autenticación y un flujo de integración adicional.
